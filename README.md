# 🎮 Tic Tac Toe

A responsive Tic Tac Toe game built using HTML, CSS, and JavaScript. It offers a clean interface, smooth gameplay, winner detection, draw detection, and a restart option.

## 🚀 Features

- Two-player gameplay (X & O)
- Automatic winner detection
- Draw detection
- Restart game functionality
- Responsive design
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
